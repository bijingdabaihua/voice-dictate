# Dictate 产品评审（v0.1 发布前）

视角：一个每天用 Claude Code / 终端写东西的中文开发者，第一次听说这个工具，
从下载到第一次成功听写，会在哪里犹豫、卡住或放弃。

## 一句话定位

**给中文开发者的本地听写键：按住左 Option 说话，松开就上屏，录音不出本机。**

不要把它讲成“又一个语音转文字工具”。真正差异点是三个词：
**中文技术语境、按住即说、完全本地**。

## 用户第一次使用的完整路径

1. 在 B 站看到视频 → 点简介里的 GitHub / Gitee
2. 打开 README → 找到 DMG → 下载 132 MB
3. 打开 DMG → 拖进 Applications
4. 第一次启动 → 被 Gatekeeper 拦截 → 去系统设置放行
5. 设置向导 → 下载 1.8 GB 模型 → 授权三项权限 → 重启
6. 按住左 Option 说第一句话 → 文字出现

这条路径里，第 4、5 步是最大的流失点。产品能控制的是把每一步解释清楚，
不能控制的是 Apple 的签名策略和模型体积。

## P0：发布前必须解决

### 1. 签名与公证

当前是 ad-hoc 签名，没有 Apple Developer ID。后果：

- 首次打开被 Gatekeeper 拦截
- 每次重新构建，TCC 权限可能失效，用户要重新授权

（v0.1 已把 Python 解释器放进 `Contents/MacOS/`，权限弹窗和系统设置里
显示 Dictate，不再是 python3。）

**建议**：如果有条件，花 99 美元/年买 Developer ID，用 `CODESIGN_IDENTITY`
构建并公证。没有条件时，至少在 README、视频、设置向导里把“被拦截怎么办”
和“升级后重新授权”写清楚。这是发布前最大的体验债。

### 2. 首次向导要能独立完成

向导现在包含模型下载、三项权限、重启，方向是对的。建议再补：

- 权限行下面加一句“为什么需要”：麦克风=录音；辅助功能=粘贴；输入监控=热键
- 模型下载显示百分比 + 已下载 MB / 总 MB + 预计剩余时间
- 下载失败时给出可重试的按钮和错误原因（网络 / 磁盘 / 镜像）
- 完成后加一个 **5 秒试用**：让用户按住说一句话，当场看到文字出现在示例框里
- “完成”按钮保持禁用，直到模型和三项权限都就绪；旁边说明还差哪一项

### 3. 权限异常要可诊断

用户最常见的求助是“热键没反应”。菜单里加一个 **权限体检**：

```
麦克风      已授权
辅助功能    未授权  [去开启]
输入监控    已授权
模型        已加载
音频设备    USB EarPods
```

体检结果可以直接复制成文本，方便发 issue。比让用户翻日志有效得多。

### 4. 发布物要可验证

- GitHub Releases 上传 DMG，附 SHA-256
- README 首屏写清楚系统要求、安装步骤、隐私边界
- 版本号和 Info.plist、README、Release 标题保持一致
- Gitee 镜像同步 Release，不只同步代码

## P1：发布后尽快做

| 功能 | 为什么 |
| --- | --- |
| 开机自启 | 听写工具应该常驻；现在每次重启要手动打开 |
| 设置窗口 | 语言、模型、麦克风、热键目前要改 JSON；普通用户不会 |
| 模型管理 | 显示已用空间、支持删除/切换 0.6B/1.7B、下载断点续传 |
| 麦克风选择 | 默认设备可能是显示器或虚拟声卡；菜单里应能选输入设备 |
| 更新检查 | 启动时检查 GitHub Releases，提示新版本；不要静默更新 |
| 麦克风重连 | 休眠/切换设备后一键重连，而不只是自动重试一次 |
| 反馈入口 | 菜单里“报告问题”直接打开 GitHub issue，附版本和日志路径 |

## P2：差异化功能（谨慎做）

- 自定义替换规则（“cloud code” → “Claude Code”）比长热词表更可控
- 按应用切换语言/热词（终端 vs 聊天 vs 邮件）
- 听写历史（默认关闭，本地保存，明确隐私开关）
- 更细的流式延迟设置（准确率 vs 上屏速度）
- 英文/日文等更多语言的预设

不要做：云同步、账号、会议记录、实时翻译。这些会把“本地小工具”的定位做散。

## 竞品与替代方案

| 方案 | 优势 | Dictate 的机会 |
| --- | --- | --- |
| macOS 自带听写 | 零安装、系统级 | 中文技术名词、中英混说、按住即说的手感 |
| Superwhisper 等付费工具 | 成熟、界面漂亮 | 免费、开源、本地、可改 |
| Whisper 命令行方案 | 模型选择多 | 不用配置 Python/模型，装完即用 |
| 输入法语音 | 与输入法结合 | 不依赖输入法，任何 App 都能用 |

视频里不要贬低系统听写，直接演示“系统听写把 Claude Code 写成 cloud code”
这种具体差异，比参数对比有说服力。

## 文案与信任

- 说“录音不上传”，不要说“完全不用联网”；首次下载模型需要联网
- 说“中英混说和技术名词表现更好”，不要说“准确率 100%”
- 说“Apple Silicon、macOS 14+”，不要暗示支持 Intel/Windows
- 明确日志默认不记录正文；`log_transcriptions` 是排错开关
- 开源许可证、第三方组件、模型许可证都放出来

## 发布节奏建议

1. **v0.1.0**：当前功能 + 修完 P0 + README/视频，GitHub Release + Gitee 镜像
2. **v0.1.x**：根据 issue 修权限、音频设备、安装问题
3. **v0.2.0**：开机自启 + 设置窗口 + 模型管理
4. **v0.3.0**：替换规则/按应用配置等差异化功能

B 站发布后重点看三类反馈：装不上、权限不生效、识别效果不符合预期。
前两类是产品问题，第三类再决定要不要换更大模型或调热词。
