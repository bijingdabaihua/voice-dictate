# Dictate v0.1.0

首个公开版本。把光标放在终端、编辑器或聊天窗口，按住听写键说话，松开后文字会粘贴到光标处。键位可以自己选：在菜单栏点「重新绑定热键…」，再按一下想用的单键。首次安装默认使用左 Option。

## 下载和安装

1. 下载附件 Dictate-0.1.0.dmg，打开并将 Dictate 拖进「应用程序」。安装包适用于 Apple Silicon Mac 和 macOS 15 或更新版本。
2. 打开应用，按向导下载约 1.8 GB 的模型，并授权麦克风、辅助功能和输入监控。当前构建未经 Apple 公证；如被拦截，可在「系统设置 → 隐私与安全性」找到启动记录后选择「仍要打开」。
3. 在任意可粘贴的输入框中试说一句。默认由你检查后按回车发送。

## 这个版本包含

- 通过 Qwen3-ASR 和 MLX 在本机听写；录音不上传，日志默认不记录正文。
- 说话时显示悬浮字幕，支持编辑技术名词热词表。
- 可选择听写时静音其他声音、粘贴后恢复剪贴板、说完自动回车。
- 菜单栏提供权限检查和重新连接麦克风。更新或替换应用后，可能需要重新授权。

## 完整性校验

把 DMG 和 SHA256SUMS.txt 下载到同一目录，运行下列命令，应看到 OK。

    shasum -a 256 -c SHA256SUMS.txt
