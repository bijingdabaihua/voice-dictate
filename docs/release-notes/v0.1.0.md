# Dictate v0.1.0

首个公开版本：按住左 Option 说话，松开后文字自动出现在光标处。完全本地运行，
音频不上传。

## 下载

- `Dictate-0.1.0.dmg`（132 MB）
- SHA-256：`36bfb171d0f12004bf3f9a29bd1f179ae3ca18a7d07e10a055957b41754956a0`

> 重新构建后校验值会变化，发布时请用实际产物的 `shasum -a 256` 替换。

## 主要功能

- 左 Option 按住说话，松开自动粘贴；`Esc` 取消
- Qwen3-ASR 0.6B + MLX，本地离线识别，流式字幕
- 中英混说，中文默认强制输出；英文技术名词保持原样
- 可编辑热词表（Claude Code、MCP 等）
- 听写时自动静音系统输出，结束恢复
- 粘贴后恢复原剪贴板
- 菜单栏可改热键、自动回车、剪贴板恢复、静音开关
- 首次启动向导：模型下载 + 麦克风/辅助功能/输入监控授权
- 日志默认不记录识别正文

## 安装

1. 下载 DMG，打开后把 Dictate 拖进 Applications
2. 从应用程序启动；若被 macOS 拦截，到「系统设置 → 隐私与安全性」点「仍要打开」
3. 按向导下载模型（约 1.8 GB）并完成三项授权
4. 如向导提示，重启 App

要求：Apple Silicon Mac、macOS 14+。

## 已知问题

- **没有 Apple Developer ID 公证**：首次打开需要手动放行；升级后可能需要重新授权
- **Intel Mac / Windows 不支持**
- **首次识别较慢**：模型首次加载需要几秒到十几秒
- **模型下载依赖网络**：默认走 hf-mirror，网络异常时可在设置向导重试

## 从源码运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python dictate.py
```

构建 App：`./packaging/build-app.sh`（自包含 + DMG）。
