# 视频制作说明

这套素材用于一条 90 秒的 B 站介绍片。目标不是广告，而是让观众在 15 秒内
看到「按住左 Option 说话 → 松手文字上屏」，然后相信它是本地、离线、可用的。

## 已经准备好的文件

| 文件 | 用途 |
|---|---|
| `script.md` | 90 秒口播、分镜、时间码、剪辑节奏 |
| `subtitles.srt` | 27 条中文字幕，可直接导入剪映 / B 站 |
| `recording-checklist.md` | 录制前、录制中、剪辑、上传的完整检查表 |
| `bilibili.md` | 5 个标题、3 套封面文案、简介、标签、置顶评论 |
| `cover-1920x1080.png` | 现成封面（深色底 + 大字） |
| `make-cover.py` | 重新生成封面的脚本 |

## 你只需要做两件事

1. **录屏**：录真实操作，不要用动画假装。
2. **配音**：用你自己的声音，开发者自述比 AI 配音可信。

其余脚本、字幕、封面、标题、简介、剪辑顺序都已经写好。

## 最省事的录制流程

### 1. 录前 10 分钟

按 `recording-checklist.md` 的「录制前」走一遍。最关键的是：

- 用 `/Applications/Dictate.app`，不要用 `dist/` 里频繁重建的副本
- 确认菜单栏状态是「就绪」，连续试 3 次「按住 → 说话 → 松手 → 粘贴」
- 打开勿扰模式，清空桌面和菜单栏，浏览器用干净配置
- 用 EarPods 或 USB 麦克风；Mac mini 没有内置麦克风

### 2. 分镜录制，不要一镜到底

每个镜头单独录，文件名建议：

```
shot03-take01.mov   第一次演示：按住说话 → HUD → 粘贴
shot04-take01.mov   中英混说：SSE / EventSource / MCP
shot05-take01.mov   关 Wi-Fi 后继续听写
shot06-take01.mov   菜单功能 + 静音演示
shot07-take01.mov   热词表
shot08-take01.mov   安装：DMG → Applications → Gatekeeper → 向导
shot09-take01.mov   GitHub / Gitee 页面
broll-menubar.mov   菜单栏图标五种状态
broll-hud.mov       悬浮字幕从短变长
```

每个镜头前后多录 2 秒；演示保留真实延迟，不要剪成“瞬间完成”。

### 3. 剪辑

用剪映专业版或 CapCut：

1. 新建 1920×1080、60fps 项目。
2. 按 `script.md` 的时间码铺镜头。
3. 导入 `subtitles.srt`，逐句校对时间码。
4. 加无版权背景音乐；0:00–0:15 留白，0:15 进入，1:20 渐弱。
5. 保留 Tink / Pop 提示音；音乐压低到不盖旁白。
6. 导出 H.264、1080p、60fps、12–20 Mbps。

### 4. 上传

按 `bilibili.md` 填标题、封面、简介、标签、置顶评论。分区选
「科技 → 计算机技术」，字幕同时上传 `subtitles.srt`。

## 发布前必须处理的两件事

1. **GitHub 仓库目前是 private**：观众点链接会 404。发布前要改成 public。
2. **还没有 Release**：把 `dist/Dictate-0.1.0.dmg` 上传到 GitHub Releases，
   视频简介和置顶评论里的下载链接才有东西可下。

Gitee 镜像也还没建；没有就先从简介里删掉 Gitee，只留 GitHub。

## 素材录好后怎么给我

放到一个固定目录，例如：

```
~/Movies/dictate-video/raw/
```

然后告诉我目录路径。我可以帮你：

- 按文件清单检查素材是否齐全、时长是否够
- 生成精确到秒的剪辑清单
- 校对字幕时间码
- 安装 ffmpeg 后做粗剪 / 拼接 / 压片（需要你确认安装）

## 不要做的事

- 不要假装“一键安装”或“完全不用联网”
- 不要展示 Windows / Intel Mac
- 不要加自动更新、云端同步、会议记录等未实现功能
- 不要说“100% 准确”

真实演示比精致包装更重要。B 站技术区观众对“演出来的丝滑”很敏感。
