## 三、简介文案

```text
按住左 Option 说话，松开自动粘贴到光标处。

一个本地识别、录音不上传的 macOS 语音输入工具，基于 Qwen3-ASR + MLX，在 Apple Silicon 上本地运行。适合在 Claude Code、Cursor、终端、浏览器和聊天窗口里代替键盘输入；中英混说和技术名词（可自定义热词）表现更好。

## 功能
- 按住左 Option 说话，松开自动粘贴
- 屏幕底部实时悬浮字幕
- 中英混说，不用切输入法
- 技术名词热词表：Claude Code、MCP 等
- 说话时自动静音系统输出，松手恢复
- 菜单栏可改热键、自动回车、粘贴后恢复剪贴板
- 本地识别：录音只在本机处理，不上传

## 系统要求
- Apple Silicon Mac（M1 及以上）
- macOS 14+
- 自包含安装包无需 Python；从源码运行需要 Python 3.10+

## 下载 / 源码
GitHub：https://github.com/bijingdabaihua/voice-dictate
Gitee：<待填>

## 首次运行
如果第一次打开被 macOS 拦截，到「系统设置 → 隐私与安全性」页面底部点「仍要打开」。当前版本没有 Apple 公证，这一步只需做一次。

首次启动会打开设置向导，下载约 1.8GB 模型，并请求以下权限：
- 麦克风
- 辅助功能（模拟 Cmd+V）
- 输入监控（监听全局热键）

辅助功能和输入监控是两个独立的列表，两个都要打开。授权后重启一次 App。
只有首次下载模型需要联网；识别过程完全离线。

## 说明
- 0.6B 模型约 1.8GB；首次启动需要下载。
- 识别延迟通常在 0.5–3 秒，取决于机器和句子长度。
- 不是 100% 准确；中英混说、技术名词可以通过热词改善。

## 致谢
Qwen3-ASR、MLX、mlx-qwen3-asr、rumps、sounddevice、PyObjC。
模型与推理库遵循 Apache-2.0；项目许可证见仓库。
```
