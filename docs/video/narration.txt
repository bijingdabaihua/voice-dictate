打字一分钟四十字，说话一分钟两百四。中间差的时间，全浪费在输入法上了。

尤其是给 Claude Code 写需求。中文、英文、技术名词混在一起，输入法切来切去，思路先断了。

所以我做了 Dictate。按住左 Option，直接说。松开就自动粘贴到光标处。

中英混说不用切输入法。Claude Code、SSE、EventSource 这些词，基本都能原样出来。

它跑在本地，用 Qwen3-ASR 和 MLX，录音不上传，断网也能用。识别一般半秒到三秒。

菜单栏里能改热键、开自动回车、粘贴后恢复剪贴板。说话的时候，它还会自动静音背景音乐，说完再恢复。

常用技术名词可以加进热词表，识别更准。

安装包是自包含的，首次启动会引导你授权麦克风、辅助功能、输入监控，并下载模型。Apple Silicon Mac，macOS 14 以上。

代码开源，GitHub 和 Gitee 都能找到，链接在简介。

按住说话，松手上屏。觉得有用的话，点个 star 或收藏。
