# Dictate 90 秒视频 · 录制检查清单

## 一、录制前

### 机器与环境

- [ ] Apple Silicon Mac（M1 及以上），macOS 14+
- [ ] 显示器分辨率设为 1920×1080 或 2560×1440，最终统一导出 1080p
- [ ] 关闭「勿扰模式」以外的所有通知：系统通知、微信、飞书、Slack、邮件
- [ ] 打开「勿扰模式」，确认录制过程中不会弹出通知
- [ ] 桌面清空：只留演示用的项目、终端、浏览器
- [ ] Dock 设为自动隐藏，或只保留必要的几个图标
- [ ] 菜单栏清理：移除个人软件图标、VPN、同步盘、密码管理器等
- [ ] 浏览器用干净的用户配置：无个人书签、无历史记录、无登录态
- [ ] 演示项目用专门的 demo 仓库，隐藏真实用户名、私有路径、API Key
- [ ] 关闭 iCloud 桌面同步和任何会在录制中弹窗的软件

### 录制软件

- [ ] OBS Studio 30+ 或 Screen Studio（推荐 OBS，免费可控）
- [ ] OBS 输出：1920×1080，60fps，H.264，CBR 30–50 Mbps
- [ ] 音频：48kHz，双音轨（音轨 1 麦克风，音轨 2 系统声音）
- [ ] 录制到本地 SSD，预留至少 10GB 空间
- [ ] 首次使用 OBS 需要在「系统设置 → 隐私与安全性 → 屏幕录制」授权
- [ ] 先录 10 秒测试片，回放确认画面清晰、没有掉帧、声音正常

### 麦克风与声音

- [ ] USB 电容麦或 EarPods 麦克风，离嘴 10–15cm
- [ ] 加防喷罩；没有的话，说话时稍微偏开麦克风
- [ ] 输入电平峰值控制在 -12dB 到 -6dB，不要爆音
- [ ] 录 10 秒环境底噪，后期降噪用
- [ ] 旁白单独录，不要和屏幕操作同时录；操作声后期再对
- [ ] 录旁白时关空调、风扇、键盘声；手机静音

### App 状态

- [ ] 提前完成三项授权：麦克风、辅助功能、输入监控
- [ ] 授权后重启一次 App，确认热键真的能用
- [ ] 模型已下载完成，菜单栏状态是「就绪」
- [ ] 热键设为左 Option
- [ ] 语言设为 Chinese
- [ ] 热词表放入：Claude Code、MCP、cc-connect
- [ ] 「说完自动回车」关闭
- [ ] 「粘贴后恢复剪贴板」打开
- [ ] 「听写时静音其他声音」打开
- [ ] 连续测试 3 次完整流程：按住 → 说话 → 松手 → 粘贴
- [ ] 确认录制期间不会弹出权限请求或系统授权框

### 演示素材

- [ ] Claude Code 终端打开一个 demo 项目，字号 18–20pt
- [ ] 浏览器打开一个空白输入框或聊天窗口，字号放大
- [ ] 准备 3 句演示台词（见下）
- [ ] 准备一段可播放的音乐/视频，用于静音演示
- [ ] 准备 `hotwords.txt` 的编辑器窗口
- [ ] 准备 GitHub 仓库页和 Gitee 镜像页
- [ ] 二维码指向项目主页或 Releases，提前用手机扫一次

### 三句演示台词

1. 帮我把这个接口改成流式输出，加上错误处理和单元测试。
2. 把这个 API 的 response 改成 SSE，前端用 EventSource 接收，MCP 那边的配置先不动。
3. 断网也能用，录音不会上传。

> 台词不要背得太顺，保留一点自然停顿；但不要有“呃、那个”太多。

## 二、录制中

### 通用

- [ ] 每个镜头单独录，开机先报板：「Shot 03，take 02」
- [ ] 每个镜头多录 2 秒头尾，方便剪辑
- [ ] 鼠标移动放慢，点击前停半秒，让观众看清位置
- [ ] 不要快速晃鼠标；需要时用 Screen Studio 的鼠标高亮/缩放
- [ ] 不要在录制中切换分辨率、缩放比例或深浅色模式
- [ ] 不要展示真实姓名、邮箱、公司名、私有仓库、聊天内容

### 演示镜头

- [ ] Shot 03：先特写菜单栏，再按左 Option；HUD 实时字幕要完整入镜
- [ ] Shot 03：松手后等文字真正粘贴出来再停止录制
- [ ] Shot 04：中英混说时，镜头要能看清英文术语没有被翻译
- [ ] Shot 05：先关 Wi-Fi，给菜单栏网络图标特写；结果出来后再开 Wi-Fi
- [ ] Shot 06：静音演示保留系统声音，让观众听到音乐消失又恢复
- [ ] Shot 07：热词文件只展示 3–5 行，不要露出个人词表
- [ ] 所有演示保留真实延迟；如果后期加速，画面上标注「加速」

### 声音

- [ ] 录到 App 的 Tink / Pop 提示音（系统音轨）
- [ ] 如果没录到，后期在对应时间点补音效
- [ ] 每个镜头录完回放一次，确认没有爆音、没有键盘撞击声
- [ ] 旁白和操作分开录时，旁白语速比平时慢 10%

## 三、录制后

### 剪辑

- [ ] 时间线：1920×1080，60fps
- [ ] 成片控制在 88–92 秒；B 站 90 秒完播率最好
- [ ] 前 3 秒必须有字或动作，不要黑屏停留
- [ ] 15 秒内出现第一次「按住说话 → 文字出现」
- [ ] 剪掉等待模型加载、权限弹窗、输入法候选框停留过久的片段
- [ ] 转场只用硬切和轻微 whoosh，不要花哨转场
- [ ] 屏幕文字用思源黑体 / PingFang SC Bold，白字黑描边，最多两行

### 字幕

- [ ] 导入 `subtitles.srt`，逐句校对时间码
- [ ] 烧录中文字幕；B 站自动字幕准确率不稳定，不要依赖
- [ ] 每行 16–20 字，最多两行；不要挡住 HUD 和菜单栏
- [ ] 技术名词保留英文原样：Claude Code、SSE、EventSource、MCP、Qwen3-ASR、MLX

### 音频

- [ ] 旁白响度 -16 到 -14 LUFS，音乐压低到 -28 到 -24 LUFS
- [ ] 整体导出 -14 LUFS，真峰值 -1dBTP
- [ ] 音乐无人声、无版权风险；优先 B 站音乐库 / Uppbeat / Artlist
- [ ] 音乐在 0:00–0:15 留白或极轻，0:15 进入，1:20 渐弱
- [ ] 保留 Tink / Pop / 键盘 / 点击声，但不要盖过旁白

### 画面

- [ ] 轻微提对比度，不要压死黑色，终端文字必须清楚
- [ ] 不要在整段画面上加滤镜或暗角
- [ ] 关键界面可加 1.05–1.1 倍缓慢推近，不要频繁缩放
- [ ] 检查每一帧：没有通知、没有个人路径、没有 API Key

### 导出

- [ ] H.264，1920×1080，60fps，16:9，12–20 Mbps
- [ ] 音频 AAC 320kbps，48kHz
- [ ] 文件名：`dictate-bilibili-v1.mp4`
- [ ] 导出后完整看一遍，确认字幕、声音、画面都对

## 五、常见翻车点

- **录制中弹出权限请求**：提前授权并重启 App，录制前再测一次。
- **重建 App 后权限失效**：ad-hoc 签名变化会作废旧授权；录制前不要重新 build。
- **Wi-Fi 关掉后 OBS 停止**：确认录制到本地，不要录到云端/网络盘。
- **通知入镜**：勿扰模式 + 关闭微信/飞书/Slack。
- **麦克风爆音**：降低输入增益，离麦远一点，录完必回放。
- **鼠标太快**：观众看不清点击位置；放慢，必要时后期放大。
- **HUD 字太小**：录制时把 HUD 放大或后期裁切放大，但不要失真。
- **分辨率不匹配**：显示器是 2560×1440 时，OBS 输出仍设 1920×1080；不要录成 4K 再压。
- **音乐版权**：不要用流行歌、影视原声；用 B 站音乐库或明确可商用的曲库。
- **夸大功能**：不要加自动更新、Windows、云端同步等未实现功能的字幕。
- **假装一键安装**：如果首版仍是脚本安装，就如实拍脚本安装；观众能看出来。
