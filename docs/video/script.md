## 一句话定位

按住左 Option 说话，松开自动粘贴到光标处；识别完全在本地，中英混说不用切输入法。

## 关键镜头执行说明

### Shot 01 · 钩子（0:00–0:05）

- 黑底白字，等宽字体，数字逐个出现；不要花哨动效。
- 第一帧就要有字，避免开头空白。
- 键盘 SFX 与数字出现对齐；这里不要铺音乐，留白更有冲击力。

### Shot 02 · 痛点（0:05–0:15）

- 真实录一段在 Claude Code 里敲需求，不要演得太夸张。
- 保留一次输入法切换、一次删改；这是开发者最有共鸣的地方。
- 终端字号 18–20pt，深色主题；隐藏用户名、私有路径、API Key。
- 如果输入法候选框不好看，可以只保留一次切换，不要反复切。

### Shot 03 · 第一次演示（0:15–0:25）

- 先给菜单栏一个特写（麦克风图标），再按左 Option。
- HUD 从屏幕底部升起，实时字幕逐字出现；不要后期加速。
- 松手后切到终端，文字粘贴；保留 Tink / Pop 提示音。
- 如果一次没识别好，重录，不要剪成“瞬间完成”。

### Shot 04 · 中英混说（0:25–0:35）

- 用浏览器输入框或聊天窗口，字号放大到观众能看清。
- 演示台词：**“把这个 API 的 response 改成 SSE，前端用 EventSource 接收，MCP 那边的配置先不动。”**
- 重点展示结果里的英文术语没有被翻译成中文，也没有被拆成奇怪的中文音译。

### Shot 05 · 离线证明（0:35–0:45）

- 先关闭 Wi-Fi，给菜单栏网络图标一个特写。
- 再说一句：**“断网也能用，录音不会上传。”**
- 结果出来后，再打开 Wi-Fi；这一个镜头不要剪断，观众要看到 Wi-Fi 确实是关的。
- 如果系统弹出“没有网络”提示，保留它，这是最好的证明。

### Shot 06 · 菜单功能（0:45–0:55）

- 逐项打开/关闭，不要一次性全点。
- 静音演示：先放一段音乐或视频，录音时声音消失，松手恢复；保留系统声音。
- 不要展示个人配置、私有仓库名、聊天记录。

### Shot 07 · 热词（0:55–1:00）

- 打开 `hotwords.txt`，展示 3–5 个词即可；不要展示很长的列表。
- 说一句同时包含 “Claude Code” 和 “MCP” 的话，展示识别结果。

### Shot 08 · 安装（1:00–1:12）

- 用干净用户或虚拟机；至少用一个空的 Applications 目录。
- 按真实顺序：下载 → 拖进 Applications → 首次打开 → Gatekeeper 放行 → 首次向导 → 三项授权 → 模型下载 → 重启。
- v0.1 没有 Apple Developer ID 公证，首次打开会被 macOS 拦截；真实拍下「系统设置 → 隐私与安全性 → 仍要打开」，不要跳过或假装没这一步。
- 模型下载如果很久，后期加速并标注“下载加速”；不要假装秒下。
- 权限向导必须真实点击，不要 P 图。

### Shot 09 · 开源（1:12–1:20）

- GitHub 页面：README 首屏、Releases、star 按钮。
- Gitee 镜像页；不要展示个人账号信息、通知红点。
- 可以给 star 按钮一个特写，但不要演“已经很多 star”。

### Shot 10 · 结束卡（1:20–1:30）

- 3 秒静态：产品名 + slogan + GitHub / Gitee + 二维码。
- 二维码指向项目主页或 Releases；上传前用手机扫一次，确认可扫。
- 背景音乐渐弱，最后一帧停留 2 秒，方便 B 站推荐图截取。

## 剪辑节奏

- 前 15 秒必须出现“按住说话 → 文字出现”的画面，不要拖到 30 秒后才演示。
- 演示段每个镜头只讲一件事；不要在同一镜头里又改设置又演示输入。
- 旁白和画面错开半拍：先说“按住左 Option”，画面再按；观众更容易跟上。
- 字幕断句按口播停顿，不要按标点硬切。
- 全片只保留一次“哇”的时刻（第一次自动粘贴）；后面是证明和功能，不要每个镜头都加特效。

## 需要避免的表述

- 不要说“支持 Windows / Intel Mac”。
- 不要说“自动更新”“云端同步”“会议记录”等尚未实现的功能。
- 不要说“100% 准确”；说“中英混说和技术名词表现更好”。
- 不要说“完全不用联网”；准确说法是“录音不上传，识别离线；首次下载模型需要联网”。
- 不要把模型下载说成“安装即用”；首次启动要等模型下载完成。
